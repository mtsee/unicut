# 重磅开源！UNICUT——纯 Web 端在线视频编辑器，功能比肩桌面端

![UNICUT 编辑器界面](https://cdn.h5ds.com/github/images/editor.png)

在视频创作全民化的今天，市面上的视频编辑工具要么需要下载安装（如剪映、PR），要么功能阉割严重（如各类轻量在线编辑器）。**有没有一款工具，既能像桌面软件一样强大，又能打开浏览器即开即用？**

今天，我们将内部打磨已久的**在线视频编辑器 UNICUT** 正式开源！

> UNICUT（爱趣五云剪辑）是一套完全运行在浏览器中的专业级视频编辑系统。无需安装、无需注册，所有素材和项目数据都可以存储在你本地的文件夹中——**素材不会上传到任何服务器**。

---

## 为什么选择 UNICUT？

### 功能齐全，覆盖完整视频创作工作流

![功能操作界面](https://cdn.h5ds.com/github/images/actions.png)

UNICUT 不是一个"玩具级"的在线编辑器，它提供了从素材管理到视频导出的**完整创作链路**：

| 模块 | 能力 |
|------|------|
| **素材库** | 12 种素材分类（视频/音频/图片/文本/特效/滤镜/Lottie/转场/字幕/模板/AI 素材/更多） |
| **画布** | 实时 WebGL 渲染预览、元素自由拖拽旋转缩放、贝塞尔曲线自定义动画路径 |
| **属性面板** | 位置/缩放/旋转/透明度/混合模式、入场/出场/强调/自定义动画、调色（亮度/对比度/饱和度 + LUT 滤镜）、蒙版、绿幕抠图、曲线变速 |
| **时间轴** | 多轨道叠加、帧级时间标尺、元素拖拽拉伸、关键帧标记、转场显示 |
| **工具栏** | 撤销/重做、分割、冻结帧、提取音频、画面裁剪、添加机位 |
| **导出** | 视频导出，支持分辨率、帧率等参数配置 |

### AI 深度集成

![AI 功能](https://cdn.h5ds.com/github/images/ai.png)

UNICUT 将 AI 能力深度融入编辑器：

- **AI 抠图** — 一键智能图像主体抠图
- **AI 去背景** — 视频/图片背景移除
- **AI 橡皮擦** — 智能物体擦除
- **AI 人像分割** — 精确人物与背景分离
- **AI 超分辨率** — 画质增强/超分辨率放大
- **AI 生图/生视频** — 文生图、图生视频
- **AI 字幕** — 语音自动转字幕
- **AI 视频跟踪** — 元素智能跟踪视频中的物体

### AI 对话助手——用自然语言操控编辑器

这是 UNICUT 最独特的亮点之一。内置的 AI 对话助手支持 **17 种 Tool Calls**，你可以用自然语言直接操作编辑器：

> "给这个元素添加 5 个残影效果"
> "把选中元素的开始时间依次增加 0.2 秒"
> "在这里剪一刀"

AI 会自动理解你的意图，调用对应的工具执行操作，无需手动点击任何按钮。同时还支持**对话历史**、视频分辨率比例设置等功能。

### 真正的"数据本地化"

UNICUT 利用浏览器原生 **File System Access API**，将你的素材和项目数据直接存储在你选择的本地文件夹中。没有中间服务器，没有云存储——**你的素材永远属于你自己**。

## 技术栈亮点

UNICUT 的技术栈堪称前端工程的教科书级实践：

| 层级 | 技术选型 |
|------|----------|
| **框架** | React 18 + TypeScript 5 |
| **状态管理** | MobX 5 |
| **UI 组件库** | Semi UI（字节跳动出品） |
| **构建工具** | Vite 4 |
| **2D 渲染** | PixiJS 7 + WebGL |
| **3D 渲染** | Three.js |
| **视频处理** | FFmpeg WebAssembly |
| **视觉 AI** | MediaPipe + ONNX Runtime Web |
| **图像处理** | OpenCV.js |
| **音频** | Howler.js + js-audio-recorder |
| **转场** | GL-Transitions |
| **动画** | Lottie Web |
| **本地存储** | File System Access API + IndexedDB (Dexie.js) |
| **视频编解码** | mp4-muxer |

一句话总结：**把桌面级视频编辑能力搬进了浏览器**。

## 快速开始

```bash
# 克隆仓库
git clone https://github.com/mtsee/unicut.git

# 安装依赖
cd unicut
yarn install

# 启动开发服务器
yarn dev
```

打开浏览器访问 `http://localhost:${PORT}`，选择一个本地文件夹作为存储目录，即可开始创作。
