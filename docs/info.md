# 项目介绍

无界云剪辑（unicut）是一款AI驱动的开源视频剪辑工具。B/S剪辑工具中全网功能最齐全。无需安装，打开浏览器即可创作。AI全程加持，让创作更高效。

# 功能强大

这并不是概念产品，而是一个实际可用的工具。功能齐全且强大，能够满足用户的各种需求。

## 元素类型支持：

- 视频
- 图片
- 花字
- 音频
- 特效
- 贴纸（lottie）
- 滤镜
- 镜头
- 字幕
- 二维码
- 图表（开发中...）
- 更多元素支持扩展

## 元素动画支持：

- lottie动画
- 转场动画
- 关键帧动画
- 元素动画
- 逐字动画
- 遮罩动画

## 元素效果支持：

- lut滤镜
- 基础滤镜
- 绿幕抠图
- webgl特效
- 不同的叠加模式
- 缩放、旋转、位移、透明度、镜像翻转
- 视频变速
- 音频变速
- 文字效果

## 元素抠图支持：

- 钢笔工具抠图
- 魔棒抠图
- AI抠图
- 裁剪抠图

## 模板/素材支持：

- 视频模板
- 图片素材
- 花字素材
- 转场素材
- 音频素材

- 特效素材
