如果你在做视频创作，大概率用过或者至少听过**剪映**。它确实是目前国内最好用的视频剪辑工具之一——功能全、模板多、上手快。

但剪映有两个让很多人头疼的问题：**收费越来越贵**（AI 功能、高级特效、去水印都要 VIP），以及**数据在云端**（你的素材和项目存在别人服务器上）。

**有没有一款工具，功能不输剪映，完全免费开源，而且数据只在你自己的电脑上？**

今天要介绍的就是——**UNICUT（无界云剪辑）**。

## 为什么 UNICUT 能替代剪映？

### 不需要安装，打开浏览器就能用

UNICUT 是一个**纯 Web 端**的视频编辑器。不装客户端、不占硬盘空间、不用担心系统兼容性。电脑上有 Chrome 或 Edge 浏览器就能打开。

但千万别以为 Web 版就是"玩具级"。UNICUT 用了一套极其硬核的技术栈——PixiJS WebGL 渲染画布、FFmpeg
WebAssembly 做视频编解码、MediaPipe + ONNX Runtime Web 做 AI 推理——**所有运算都在浏览器本地完成，性能不输原生应用**。

## AI 能力直接拉满

UNICUT 的免费 AI 功能已经全面覆盖创作流程的各个环节：

- **AI 抠图**：基于 MediaPipe 深度学习模型，一键分离主体和背景，推理在浏览器本地完成
- **AI 人像分离**：精确分割人物与背景，不逊色于桌面端效果
- **AI 图像超分辨率**：低分辨率素材一键变清晰，老照片和低画质视频有救了
- **AI 橡皮擦**：涂抹式智能擦除水印和不需要的物体
- **AI 视频轨迹追踪**：让贴纸和文字自动跟随视频中的物体移动
- **AI 自动识别素材内容**：自动分析素材并智能打标签，方便管理和检索
- **AI 自动剪辑**：智能分析视频内容，自动选取精彩片段

同时，UNICUT 也提供了 AI 字幕、AI 文字转语音、AI 生图/生视频等高级 AI 功能，按需付费使用。

### 更绝的——用自然语言剪视频

这是剪映目前完全没有的功能。UNICUT 内置了一个 AI 对话助手，接入了 17 种底层工具。你只需要用自然语言下指令：

> "给这个元素加 5 个残影效果" "在 3 秒的位置剪一刀" "透明度依次减少 20%" "把选中元素的开始时间依次加 0.2 秒"

AI 会自动调用对应工具，完成操作。不用找按钮、不用记快捷键——**你跟它聊天，它就帮你剪。**

## 数据只在你自己的电脑上

这是 UNICUT 和剪映最根本的区别。

剪映的项目文件、素材、云端草稿都存在服务器上。而 UNICUT 利用**浏览器 File System Access
API**，让你选择一个本地文件夹作为工作目录。所有素材和项目数据直接存储在这个文件夹里——**没有中间服务器，没有云存储，你的素材永远属于你自己**。

对于企业用户、MCN 机构、或者任何在意数据隐私的创作者来说，这是一个刚需级别的差异。

## 开源意味着什么？

这意味着：

- **完全免费**：没有功能限制，没有水印，没有付费墙
- **代码透明**：你可以看到每一行代码，不用担心后门或隐私泄露
- **可定制**：企业可以基于 UNICUT 二次开发，定制自己的剪辑工具
- **社区驱动**：Bug 修复、功能迭代由社区共同推进

## 快速开始

```bash
git clone https://github.com/your-org/unicut.git
cd unicut
yarn install
yarn dev
```

打开浏览器，选择一个本地文件夹，开始创作。
