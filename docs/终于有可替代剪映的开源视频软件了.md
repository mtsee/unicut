# 终于有可替代剪映的开源视频软件了

剪映作为目前国内最流行的视频剪辑工具，功能强大但一直闭源。很多开发者和企业用户都在寻找一款能够替代剪映的开源方案——现在，它来了。

## 无界云剪（unicut）是什么？

[无界云剪](https://unicut.h5ds.com/) 是一款 **AI 驱动的开源视频剪辑工具**，也是目前 B/S 架构剪辑工具中全网功能最齐全的一款。无需安装任何软件，打开浏览器就能直接开始创作，AI 全程加持，让视频创作更高效。

## 功能到底有多强？

这不是一个概念 Demo，而是一个真正可用的产品。看看它的功能清单：

### 元素类型
支持视频、图片、花字、音频、特效、贴纸（Lottie）、滤镜、镜头、字幕、二维码、图表（开发中）等多种元素类型，并且支持扩展更多类型。

### 动画系统
- Lottie 动画
- 转场动画
- 关键帧动画
- 元素动画
- 逐字动画
- 遮罩动画

### 视觉效果
- LUT 滤镜 / 基础滤镜
- 绿幕抠图
- WebGL 特效
- 多种叠加模式
- 缩放、旋转、位移、透明度、镜像翻转
- 视频变速 / 音频变速
- 丰富的文字效果

### 抠图能力
支持钢笔工具抠图、魔棒抠图、AI 抠图、裁剪抠图等多种抠图方式。

### 模板与素材
提供视频模板、图片素材、花字素材、转场素材、音频素材、贴纸素材、滤镜素材、特效素材等丰富的素材库。
