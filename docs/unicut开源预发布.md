## 🎯 我们为什么要做 UNICUT？

目前市面上的 Web 端剪辑工具大多是「玩具级」：要么功能少得可怜，要么剪辑逻辑反人类，要么核心功能锁付费，根本没法满足正经的创作需求。而桌面端工具又太重，安装麻烦、占用空间大、跨设备同步难。

我们想做一款**真正能用、好用、免费**的 Web 端剪辑工具：

- ✅ 功能对标桌面级，不用再装客户端
- ✅ AI 能力深度集成，让剪辑效率翻倍
- ✅ 数据完全本地化，素材不上传服务器
- ✅ 完全开源免费，没有功能阉割

## 🌟 核心特性，这才是你想要的剪辑工具

### 🔌 零安装，打开浏览器就能用

不用下载几个G的安装包，不用激活，不用登录，打开 Chrome/Edge 浏览器就能开始创作。

### 🔒 数据完全本地化

基于浏览器 File System Access API，所有素材和项目都存在你自己的本地文件夹里，不会上传到任何服务器，隐私有保障。

### 🆓 完全开源免费

所有核心剪辑功能永久免费，没有水印、没有导出限制、没有功能阉割。企业可以直接二次开发，定制自己的剪辑工具。

### 🧩 插件可扩展

支持插件机制，你可以基于 UNICUT 开发自己的专属功能，比如自定义特效、企业内部素材库、特定行业模板等。

### 快速开始（上线后可用）

```bash
git clone https://github.com/mtsee/unicut.git
cd unicut
yarn install
yarn dev
```

打开浏览器访问 `http://localhost:3000`，选择一个本地文件夹，开始创作。
