# 天下苦剪映久已

"天下苦剪映久已"——这句话在剪辑圈里流传已久。

剪映确实好用，但问题也摆在那：

- **闭源**，你永远不知道它在后台做了什么
- **强制联网**，离线使用受限
- **素材必须上传云端**，隐私安全全靠信任
- **收费项目越来越多**，VIP、SVIP、各种单独付费
- **不能私有化部署**，企业想用？没门

而市场上能打的 B/S 剪辑工具，几乎没有。

所以我们做了一个决定：**自己做一款，然后开源**。

## 无界云剪，开源的力量

![编辑器](https://cdn.h5ds.com/github/images/editor.png)

[无界云剪（unicut）](https://unicut.h5ds.com/) 是一款 AI 驱动的开源视频剪辑工具，浏览器打开即用，目前 B/S 架构中全网功能最齐全。

### 真正的数据本地化

你的素材、你的项目，全部存储在你自己选择的本地文件夹里。没有任何数据上传到服务器。不是承诺，是架构决定——利用浏览器 File System Access API，从底层杜绝了隐私泄露的可能。

## 功能，不妥协

这不是一个"玩具"。它是认真的视频编辑工具。

### 元素类型

视频、图片、花字、音频、特效、贴纸（Lottie）、滤镜、镜头、字幕、二维码、图表（开发中），支持插件扩展。

### 动画能力

Lottie 动画、转场动画、关键帧动画、元素动画、逐字动画、遮罩动画——你剪映里常用的，这里都有。

### 视觉效果

LUT 滤镜、基础滤镜、绿幕抠图、WebGL 特效、叠加模式、缩放旋转位移透明度镜像翻转、视频变速、音频变速、文字效果。

### 抠图

钢笔抠图、魔棒抠图、AI 抠图、裁剪抠图，四种方式覆盖从精细到快速的全场景。

### 素材生态

视频模板、图片、花字、转场、音频、贴纸、滤镜、特效素材，完整素材库。

## 专业时间轴

元素分割裁剪、批量操作、帧图预览、音波预览、多轨道编辑、隐藏锁定吸附、时间轴缩放、撤销重做、定格、尺寸裁剪、时间裁剪——专业剪辑工作流完整闭环。
