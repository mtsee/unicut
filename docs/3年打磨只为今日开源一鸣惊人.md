# 3 年打磨，只为今日开源，一鸣惊人

三年前，我们开始做一件事：在浏览器里复刻一个功能完整的视频编辑器。

那时候很多人觉得不可能。浏览器能跑得动吗？渲染性能够吗？FFmpeg 在 Web 端能行吗？

三年后，我们把它开源了。

它叫 **无界云剪（unicut）**，一款 AI 驱动的开源视频剪辑工具，B/S 架构中全网功能最齐全，没有之一。

## 三年，我们做了什么

### 元素体系

支持视频、图片、花字、音频、特效、贴纸（Lottie）、滤镜、镜头、字幕、二维码、图表（开发中）等十余种元素类型，并且架构上支持无限扩展。

### 动画引擎

从零搭建了一套完整的动画系统：

- Lottie 动画
- 转场动画
- 关键帧动画
- 元素动画
- 逐字动画
- 遮罩动画

### 视觉效果

LUT 滤镜、基础滤镜、绿幕抠图、WebGL 特效、混合模式、缩放旋转位移透明度镜像翻转、视频变速、音频变速、文字效果——每一项都是手写。

### 抠图方案

钢笔工具抠图、魔棒抠图、AI 抠图、裁剪抠图，四种方式覆盖不同精度需求。

### 素材生态

视频模板、图片素材、花字素材、转场素材、音频素材、贴纸素材、滤镜素材、特效素材，完整素材库。

## AI 能力，不是贴牌

![AI功能](https://cdn.h5ds.com/github/images/ai.png)

很多产品号称集成 AI，实际就是接了个 API。我们不一样——大量 AI 能力是端侧直接运行的（MediaPipe + ONNX Runtime Web）：

| 功能          | 实现方式 | 费用 |
| ----------- | ---- | -- |
| AI 自动识别素材内容 | 端侧   | 免费 |
| AI 自动剪辑     | 端侧   | 免费 |
| AI 人像分离     | 端侧   | 免费 |
| AI 图像变清晰    | 端侧   | 免费 |
| AI 涂抹       | 端侧   | 免费 |
| AI 抠图       | 端侧   | 免费 |
| AI 视频轨迹追踪   | 端侧   | 免费 |
| AI 生成字幕     | 服务端  | 收费 |
| AI 文字转语音    | 服务端  | 收费 |
| AI 自动生成图片   | 服务端  | 收费 |
| AI 自动生成视频   | 服务端  | 收费 |

7 项端侧 AI 能力完全免费，数据不出浏览器。

## 专业时间轴，三年磨一剑

时间轴是剪辑工具的灵魂，也是最难写的部分。我们实现了：

- 元素分割裁剪
- 批量操作选择 / 拖动
- 帧图预览 / 音波预览
- 多轨道编辑
- 隐藏 / 锁定 / 吸附
- 时间轴缩放
- 撤销 / 重做
- 定格元素
- 元素尺寸裁剪
- 视频时间裁剪

## 为什么开源

打磨了三年的产品，为什么要开源？

因为我们相信：**好的工具不应该被锁在围墙里**。剪映很好，但它闭源。Adobe 很专业，但成本高昂。我们想让每个人、每个团队都能拥有一个可自由定制的视频编辑工具——不管你是个人创作者，还是需要私有化部署的 SaaS 企业。
